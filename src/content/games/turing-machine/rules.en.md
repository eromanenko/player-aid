## Setup
Choose a problem from the rulebook or the web app. Place the required criteria cards around the central machine tile. Give each player a player aid and a dry-erase note sheet.

## Gameplay
Turing Machine is a competitive deduction game. Your goal is to find the secret 3-digit code (each digit is from 1 to 5) before anyone else.

The game is played in simultaneous rounds. Each round has these phases:
1. **Compose a Code:** Each player secretly chooses a 3-digit code they want to test and takes the corresponding three punch-cards (blue triangle, yellow square, purple circle). Stack them together. Only one 3-digit number will be visible through the hole!
2. **Question the Machine:** Test your code against up to 3 criteria cards. Place your stacked punch-cards on a criteria card and look through the hole on the back. 
   - **Green Checkmark:** Your code satisfies this specific criterion!
   - **Red Cross:** Your code does NOT satisfy this criterion.
3. **Deduce:** Use the information to deduce the final code on your note sheet.
4. **End of Round:** Players simultaneously point a thumb up (ready to guess the final code) or down (need another round).

## Winning
If you gave a thumbs up, write down your guess for the secret code. 
Check the solution in the rulebook or app. 
- If you are correct, you win! 
- If multiple players are correct in the same round, the player who asked the FEWEST total questions to the machine wins.
- If you guessed incorrectly, you are eliminated!
