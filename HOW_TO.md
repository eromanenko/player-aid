# Довідник: Як працює проект та як додавати нові ігри

Цей документ створено для передачі контексту новим сесіям AI, щоб уникнути повторних помилок та зберегти знання про архітектуру проекту.

## 🏗 Архітектура проекту
- **Фреймворк**: Next.js 15 (App Router).
- **Важливе правило Next.js 15**: Усі динамічні параметри сторінок (`params`, `searchParams`) є асинхронними і їх **обов'язково** треба чекати (`const { lang } = await params;`).
- **Локалізація**: Використовується папка `src/app/[lang]/`. Редирект на мову за замовчуванням (`/uk`) обробляється у файлі `src/proxy.ts` (Next.js Middleware).
- **Зображення**: BGG API блокує запити через Cloudflare (помилка 401). Тому всі обкладинки ігор ми зберігаємо **локально** як статичні файли в папці `public/games/[id]/cover.jpg`.
  - *Примітка:* Щоб Next.js віддавав картинки і не перенаправляв їх на `/uk/...`, шлях `games/` додано до винятків у `matcher` всередині `src/proxy.ts`.

## 🎮 Як додати нову гру
Коли користувач кидає посилання на BGG (наприклад, `https://boardgamegeek.com/boardgame/346703/7-wonders-architects`), AI повинен зробити наступні кроки:

### 1. Створити файли контенту
У папці `src/content/games/` створіть нову папку з ID гри (наприклад, `7-wonders-architects`).
У ній створіть Markdown файли для кожної мови: `rules.uk.md`, `rules.ru.md`, `rules.en.md`.

Кожен файл повинен мати такий Frontmatter (`gray-matter`):
```yaml
---
title: "Назва гри"
players: "2-7"
time: "25"
bggId: 346703
expansions:
  - id: "expansion-1"
    name: "Назва доповнення"
---

Тут йде текст правил у форматі Markdown.
```

### 2. Завантажити обкладинку (Cover)
Оскільки динамічний `fetch` до BGG API не працює через Cloudflare, треба зберегти обкладинку локально:
1. Використати скрипт `node download-covers.js` (який використовує Puppeteer для обходу Cloudflare), щоб автоматично завантажити обкладинку за `bggId`.
2. АБО завантажити зображення вручну (чи за допомогою AI інструментів) і покласти файл у **ДВА** місця:
   - `src/content/games/[id]/cover.jpg` (для збереження в контенті).
   - `public/games/[id]/cover.jpg` (для того, щоб Next.js міг віддавати його браузеру на сторінках).

### 3. Оновити список ігор (не потрібно)
Вам не потрібно правити списки вручну. Функція `getAllGames` у `src/lib/games.ts` автоматично просканує папку `src/content/games/`, прочитає frontmatter, згенерує ключі для пошуку (`searchTerms`) і автоматично пропише шлях до картинки `thumbnail: "/games/[id]/cover.jpg"`.

---

**🤖 Інструкція для ШІ (наступного чату):**
Якщо користувач просить "додай таку-то гру за посиланням BGG", ти маєш:
1. Прочитати цей `HOW_TO.md`.
2. Знайти/згенерувати текст правил та створити `rules.*.md` файли в `src/content/games/`.
3. Забезпечити збереження обкладинки `cover.jpg` в `public/games/[id]/`.
4. Перевірити роботу в браузері (але пам'ятати, що Next.js 15 кешує `public/` і можливо користувачу треба буде перезапустити `npm run dev` якщо з'явилась нова папка в `public/`).
